# Изменения

## 0.2.0

- Иконка приложения теперь такая же, как на сайте.
- Значки типов разъёмов — те же, что на сайте; видны в карточке станции и в
  фильтрах.
- Язык берётся из языка телефона. Если он не русский, кыргызский или
  английский — интерфейс будет английским. Выбор в настройках по-прежнему
  главнее.
- Кнопка «приложение сети» у SPARK открывает сразу нужную станцию. Остальные
  сети так не умеют, и приложение теперь честно об этом говорит, а не оставляет
  искать точку глазами.
- Обновление карты стало легче почти в девять раз: 6 КБ вместо 54. Полный
  список подгружается, только когда состав станций изменился.

## 0.1.3

- Проверочный выпуск: подтверждает, что обновление скачивается и ставится.

## 0.1.2

- Обновление снова устанавливается. Скачанный APK лежал в общих «Загрузках»,
  где приложение при scoped storage не видит даже собственный файл, и
  установщик молча не открывался. Теперь файл качается в каталог приложения.
- Размер загрузки показывается в местных единицах: МБ вместо MB.

## 0.1.1

- Метки на карте сводятся в группы: в центре Бишкека четыреста станций больше
  не налезают друг на друга.
- Кольцо занятости не пропадает у станций с большим числом портов.
- Отсутствие релизов на GitHub больше не показывается как ошибка.

## 0.1.0

Первая версия.

- Карта зарядных станций Кыргызстана на osmdroid: SPARK, We way, EVION,
  Charge24. Метка показывает занятость кольцом по числу портов.
- Список ближайших с временем в пути; когда маршрутизация недоступна,
  расстояние честно подписано «по прямой».
- Фильтры: сеть, тип разъёма, мощность, только свободные.
- Карточка станции: разъёмы, цены, акции и ограничения доступа, состав
  склеенной площадки, маршрут в выбранном навигаторе, запуск приложения сети,
  «поделиться», копирование координат.
- Три языка — русский, кыргызский, английский; светлая и тёмная темы, цвета из
  обоев.
- Работа без сети: последняя карта показывается из кэша, занятость при этом
  помечается неизвестной.
- Обновление через GitHub Releases с показом размера загрузки.
